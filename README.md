# Professional MERN Portfolio

## Setup
1. MongoDB: Get URI from Atlas (free tier).
2. Backend: `cd backend`, copy `.env.example` to `.env`, add DB URI, `npm i`, `npm run dev`.
3. Frontend: `cd frontend`, `npm i`, `npm run dev`.
4. Seed: `cd backend`, `node seed.js`.

## Features
- Responsive Tailwind design, dark/light mode.
- Dynamic projects from MongoDB.
- Contact form.

## Customize
Edit components with your info/images.

Ports: Backend 5000, Frontend 3000.
